## Stardew Valley 3D

This project is a simple test of rendering Stardew Valley in 3D via Raytracing with ILGPU (currently).

## Demo Video:
[![Watch the video](https://img.youtube.com/vi/JUw2vLFNYhA/hqdefault.jpg)](https://youtu.be/JUw2vLFNYhA)

Workflow:

Game loads → Tiles auto-register with smart defaults
Press F8 → Enter editor mode
Hover over tile → Press Ctrl+2 → Configure properties
Changes apply immediately → Only that mesh regenerates
Press F9 → Save all metadata to disk
Share JSON files → Other users get same configuration
